---
title: Authoring
description: Create a dojo in your editor or together with an agent in the authoring UI.
---

A dojo is a folder of teaching material, lesson files, and a manifest. You own the files and can keep them in Git. The authoring UI edits those same files; it isn't a separate publishing format.

- [Create a dojo manually](/authoring/manual) using an existing starter and your editor.
- [Use the authoring UI](/authoring/authoring-ui) to build lessons together with Kyoshi, the authoring agent.

Start with one lesson: define what the learner should understand, provide an exercise, and try it as a student before expanding the course.
